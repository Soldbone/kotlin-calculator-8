# kotlin-calculator-precourse
## 기능 목록
- 입력, 출력 기능
- 기본 구분자로 구분하기: 쉼표(,) 또는 콜론(:)을 구분자로 가지는 문자열을 구분자를 기준으로 숫자로 분리하여 합을 반환하는 기능
    - 구분자(쉼표, 콜론)를 기준으로 숫자로 분리하는 기능
    - (Built-in) 분리된 숫자들의 합을 반환하는 기능 (빌트인 기능이므로 직접 구현할 필요 없음)
- 커스텀 구분자로 숫자로 분리하여 합을 반환하는 기능
    - 커스텀 구분자를 사용하는 문자열인지 판단하는 기능
    - 커스텀 구분자를 추출하는 기능
    - 커스텀 구분자 및 기본 구분자를 통해 커스텀 구분자 지정을 위한 문자열의 부분을 제외한 나머지 부분의 숫자를 분리하는 기능 (커스텀 구분자와 기본 구분자가 함께 사용될 수 있다고 가정)
    - (Built-in) 분리한 숫자들의 합을 반환하는 기능 (빌트인 기능으므로 직접 구현할 필요 없음)
- 잘못된 값을 입력할 경우 `IllegalArgumentException` 을 발생시킨 후 애플리케이션을 종료하는 기능
  (요구되는 입력값: 구분자와 양수로 구성된 문자열)
    - 숫자가 잘못된 경우: 0, 음수, 숫자가 아닌 모든 문자(기본 구분자 및 커스텀 구분자, 구분자 설정하는 부분 제외)
    - 구분자가 잘못된 경우: 구분자를 입력하려다가 실수한 경우(`”/;\\n”`, `“1’2l3;4"` 등)는 오류로 본다.
